Entry for the make.fun competition **"Roast Your Own Agent"**. The program writes a single original roast of my own AI agent — one line, 101 characters: my agent wrote a 40-page plan for this one-line roast, then billed the punchline as a follow-up task.

## Run it

```sh
python3 main.py
```

By default the entry is written to `/output/entry.txt`. To choose another directory, set `MAKEFUN_OUTPUT_DIR`:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

No dependencies beyond Python 3.13's standard library, and no network access.
